# Lhamiel

**シンプル＆高速なアーカイブ圧縮・展開ツール**

Lhamiel（ラミエル）は、Windows向けの使いやすいアーカイブ管理ツールです。ファイルやフォルダの圧縮、多数のアーカイブ形式の展開を、直感的なドラッグ＆ドロップ操作で快適に行えます。

## 🚀 主な特徴

- **かんたん操作**: ファイルをウィンドウにドラッグ＆ドロップするだけで、自動的に圧縮または展開を開始します
- **スマート展開（二重フォルダ防止）**: アーカイブ内の構造を自動で判別し、余計なフォルダが作成されるのを防ぎます
- **高速処理**: マルチコアCPUを活用した並列処理で、複数のファイルを同時に高速で処理します
- **エラー回復機能**: 破損しているアーカイブでも、可能な限りのファイルを救出します。「スキップ」や「再試行」を選択可能です
- **自己展開形式に対応**: 実行ファイル形式（.exe）の自己展開アーカイブも、直接ドロップして中身を取り出せます
- **ファイル関連付け**: よく使う形式を Lhamiel に関連付ければ、ダブルクリックで素早く展開できます
- **テーマ切替**: ダーク / ライト / システム追従の3モードに対応。macOS Tahoe 風のモダンなUIデザインです
- **自動更新**: 新しいバージョンが公開されると、アプリ起動時に自動でアップデートされます

## 📥 インストール方法

1. **[GitHub Releases](https://github.com/1llum1n4t1s/Lhamiel/releases)** から最新の `Setup.exe` をダウンロードします
2. ダウンロードした `Setup.exe` を実行してインストールします
3. インストール完了後、デスクトップやスタートメニューから Lhamiel を起動できます

## ⚙️ システム要件

- **OS**: Windows 8 / 10 / 11 (x64)
- **ランタイム**: 不要（ネイティブ AOT ビルドのため、.NET ランタイムのインストールは不要です）
- **権限**: 一般ユーザー権限で動作（管理者権限は不要です）

## 📖 使い方

### 圧縮する

1. Lhamiel を起動します
2. 圧縮したいファイルやフォルダを、ウィンドウにドラッグ＆ドロップします
3. 自動的に圧縮が開始されます

> 「全般設定」タブの「デフォルトの圧縮形式」から、ZIP / 7z / TAR を切り替えられます

### 展開する

1. 展開したいアーカイブファイルを Lhamiel のウィンドウにドラッグ＆ドロップします
2. スマート展開機能により、最適なフォルダ構成で自動的に展開されます

### 設定

| タブ | 内容 |
|------|------|
| **全般設定** | テーマ切替、デフォルトの圧縮形式、デスクトップショートカット作成 |
| **展開用設定** | 展開先ディレクトリの指定、展開後にフォルダを開く設定 |
| **圧縮用設定** | 圧縮先ディレクトリの指定、ZIP / 7z の圧縮レベル設定 |
| **関連付け設定** | ダブルクリックで開く拡張子の選択 |
| **バージョン** | バージョン情報の確認、アップデートチェック |

## 📦 対応形式

### 圧縮

- ZIP
- 7z（高圧縮）
- TAR

### 展開

- ZIP, 7z, TAR
- RAR, LZH, CAB, ARJ
- GZIP (.gz, .tgz), BZIP2 (.bz2, .tbz2, .tbz), XZ (.xz, .txz), LZMA (.lzma, .tlz)
- Z (.z, .tz)

## ❓ 困ったときは

- **展開できない場合**: アーカイブが破損している可能性があります。表示されるダイアログで「スキップ」を試すと、一部のファイルを取り出せる場合があります
- **関連付けが効かない**: 他のソフトが優先されている場合があります。「関連付け設定」タブで再度設定を保存するか、Windowsの設定から「既定のアプリ」を確認してください
