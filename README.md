# Lhamiel

Lhamiel は、Windows 向けのシンプルなアーカイブ圧縮・展開ツールです。

## ダウンロード

インストーラーは以下からダウンロードできます。

- **インストーラー（Windows）**: https://github.com/1llum1n4t1s/Lhamiel/releases

Releases の Assets から `Setup.exe` をダウンロードしてください。

## システム要件

- **OS**: Windows 10 (ビルド 26100.0) 以上
- **フレームワーク**: .NET 10.0 Runtime（インストーラーに含まれます）
- **アーキテクチャ**: x64
- **必要な権限**: ユーザー権限（管理者権限不要）

## インストール

1. [Releases ページ](https://github.com/1llum1n4t1s/Lhamiel/releases) から `Setup.exe` をダウンロードします。
2. ダウンロードした `Setup.exe` を実行してインストールします。

インストール時に以下が自動的に実行されます：

- Windows のアプリケーション一覧に「Lhamiel」として登録
- スタートメニューにショートカットを作成
- デスクトップにショートカットを作成

## 主な機能

- **圧縮・展開**: ファイルやフォルダの圧縮とアーカイブの展開に対応
- **出力先指定**: 圧縮/展開それぞれの出力先を指定、または元のファイルと同じ場所に出力
- **形式選択**: 圧縮形式を選択可能（設定は次回起動時も保持されます）
- **ファイル関連付け**: 対応拡張子のファイル関連付けを GUI から一括設定・解除
- **進捗表示**: 処理の進捗をリアルタイムで表示し、キャンセル操作にも対応
- **自動更新**: 新しいバージョンが利用可能になると自動的に更新されます

## 対応形式

### 圧縮対応

7z / xz / bz2 / gz / tar / zip / wim / cab

### 展開対応

zip / 7z / tar / gz / bz2 / lzma / xz / rar / lzh / cab / arj / z / 自己解凍形式（.exe）

## 使い方

### 圧縮

1. アプリを起動します。
2. 「圧縮」タブで圧縮したいファイルまたはフォルダを選択します。
3. 圧縮形式を選択します。
4. 必要に応じて出力先を指定します（未指定の場合は元のファイルと同じ場所に出力されます）。
5. 「圧縮」ボタンをクリックします。

### 展開

1. アプリを起動します。
2. 「展開」タブで展開したいアーカイブファイルを選択します。
3. 必要に応じて出力先を指定します（未指定の場合は元のファイルと同じ場所に出力されます）。
4. 「展開」ボタンをクリックします。

### ファイル関連付け

1. アプリを起動します。
2. 「設定」タブを開きます。
3. 関連付けたい拡張子にチェックを入れます（全選択・全解除ボタンも利用できます）。
4. 関連付けを行うと、該当するファイルをダブルクリックすることで Lhamiel で開けるようになります。

## アンインストール

### 方法 1: Windows の設定から

1. Windows の設定から「アプリ」→「インストール済みアプリ」を開きます。
2. 「Lhamiel」を検索して選択します。
3. 「アンインストール」をクリックします。
4. 確認画面で「アンインストール」を再度クリックします。

### 方法 2: コントロールパネルから

コントロールパネルの「プログラムと機能」から Lhamiel を選択してアンインストールできます。

アンインストール時に以下が自動的に削除されます：

- インストール済みファイル
- ファイル関連付け
- 作成されたショートカット
- アプリケーション一覧からのエントリ
