# Lhamiel

**シンプル＆高速なアーカイブ圧縮・展開ツール**

Lhamiel（ラミエル）は、Windows向けの使いやすいアーカイブ管理ツールです。ファイルやフォルダの圧縮、複数のアーカイブ形式への対応、直感的なドラッグ&ドロップUIで、快適なファイル操作を実現します。

## 🚀 主な特徴

- **シンプルな操作**: ドラッグ&ドロップで圧縮・展開
- **スマート展開（二重フォルダ防止）**: アーカイブ内の構造を自動判別。展開時に余計なフォルダが作成されるのを防ぎ、デスクトップや作業フォルダを綺麗に保ちます。
- **高速な並列処理**: マルチコアCPUを最大限に活用し、複数のアーカイブを同時に高速処理します。
- **エラー回復機能**: 破損したアーカイブでも、可能な限りのファイルを救出。エラー発生時に「スキップ」や「再試行」を選択できます。
- **自己展開形式対応**: 実行ファイル形式（.exe）の自己展開アーカイブも直接展開可能。
- **豊富な展開形式対応**: ZIP、7z、RAR、tar、gz、lzh など多数の形式に対応
- **複数の圧縮形式**: ZIP、7z、TAR で圧縮
- **ファイル関連付け**: 対応形式のファイルをダブルクリックで自動処理
- **柔軟な出力先設定**: 元のファイルと同じ場所か、指定した場所に出力を選択可能
- **進捗表示**: 処理の進行状況をリアルタイムで確認でき、キャンセルも可能
- **自動更新**: 新しいバージョンが利用可能になると自動更新
- **管理者権限不要**: 一般ユーザー権限で動作

## 📖 使い方

### 圧縮する

#### 方法1: メイン画面から圧縮

1. アプリケーションを起動して「ファイル操作」タブを開きます
2. 「ファイルを圧縮」をクリックして、圧縮したいファイルやフォルダを選択します（複数選択可）
3. 圧縮形式を選択します（ZIP、7z、TAR から選択）
4. 出力先を設定します：
   - **元のファイルと同じ場所**: ファイルやフォルダのある場所に圧縮ファイルを作成
   - **指定した場所**: 別のフォルダを指定して圧縮ファイルを作成
5. 「ファイルを圧縮」ボタンをクリックします

#### 方法2: ドラッグ&ドロップで圧縮

1. アプリケーションを起動します
2. ファイルやフォルダをアプリケーションのドロップゾーンにドラッグ&ドロップします
3. 自動的に圧縮が開始されます（複数の項目を一度にドロップすると、並列で高速に処理されます）

#### 方法3: ファイル関連付けで圧縮

1. 「関連付け設定」タブで対応形式をチェック（ファイル関連付けを有効化）
2. エクスプローラーで任意のファイルを右クリック
3. 「プログラムから開く」→「Lhamiel」を選択して圧縮

### 展開する

#### 方法1: メイン画面から展開

1. アプリケーションを起動して「ファイル操作」タブを開きます
2. 「アーカイブを展開」をクリックして、展開したいアーカイブファイルを選択します（複数選択可）
3. 出力先を設定します：
   - **元のファイルと同じ場所**: アーカイブのある場所にファイルを展開
   - **指定した場所**: 別のフォルダを指定してファイルを展開
4. 「アーカイブを展開」ボタンをクリックします

#### 方法2: ドラッグ&ドロップで展開

1. アプリケーションを起動します
2. アーカイブファイルをアプリケーションのドロップゾーンにドラッグ&ドロップします
3. 自動的に展開が開始されます（スマート展開機能により、最適なフォルダ構成で展開されます）

#### 方法3: ダブルクリックで展開

1. 「関連付け設定」タブで対応形式をチェック（ファイル関連付けを有効化）
2. エクスプローラーでアーカイブファイルをダブルクリック
3. 自動的に展開されます

### ファイル関連付けの設定

1. アプリケーションを起動して「関連付け設定」タブを開きます
2. 対応させたい拡張子にチェックを入れます
   - 「全選択」: すべての形式に関連付け
   - 「全解除」: すべての関連付けを削除
3. 「設定を保存」をクリック

完了後、対応形式のファイルをダブルクリックすることで Lhamiel で自動的に処理できるようになります。

## 📦 対応形式

### 圧縮対応形式

以下の形式で新しいアーカイブを作成できます：

- ZIP
- 7z（セブンジップ）
- TAR

### 展開対応形式

以下の形式のアーカイブを展開できます：

- ZIP
- 7z（セブンジップ）
- TAR / GZIP（.gz, .tgz） / BZIP2（.bz2, .tbz2, .tbz）
- XZ（.xz, .txz） / LZMA（.lzma, .tlz）
- RAR
- LZH
- CAB
- ARJ
- Z（.z, .tz）
- EXE（自己展開形式）

## ⚙️ 詳細設定

### 出力先フォルダの指定

- **圧縮の出力先**: 圧縮後のアーカイブファイルを保存するフォルダを指定
- **展開の出力先**: 展開後のファイルを保存するフォルダを指定

デフォルトでは、元のファイルと同じフォルダに出力されます。

### 処理後の動作設定

「圧縮用設定」または「展開用設定」タブで以下の項目をチェックすることで、処理完了後に自動的に出力フォルダを開くことができます：

- **圧縮後にフォルダを開く**: 圧縮完了後に出力フォルダをエクスプローラーで開く
- **展開後にフォルダを開く**: 展開完了後に出力フォルダをエクスプローラーで開く

### スマート展開機能について

Lhamielは展開時にアーカイブ内をスキャンし、以下のように動作します：
- **中身が1つのフォルダにまとまっている場合**: そのフォルダを直接展開します（二重フォルダを防止）。
- **中身がバラバラの複数のファイルの場合**: アーカイブ名と同じ名前のフォルダを自動作成し、その中に展開します。

### 自動更新機能

アプリケーションは起動時に自動的に新しいバージョンをチェックします。新しいバージョンが利用可能な場合、自動的にダウンロードして更新されます。更新後はアプリケーションが再起動されます。

## 🗑️ アンインストール

### Windows 設定から削除

1. Windows の設定を開きます
2. 「アプリ」→「インストール済みアプリ」から「Lhamiel」を検索
3. 「アンインストール」をクリック
4. 確認画面で「アンインストール」をクリック

1. Windows のコントロールパネルを開きます
2. 「プログラムと機能」から「Lhamiel」を選択
3. 「アンインストール」をクリック

アンインストール後、以下は自動的に削除されます：

- インストール済みファイル
- ファイル関連付け設定
- ショートカット
- アプリケーション一覧のエントリ

## ❓ トラブルシューティング

### アーカイブが展開できない / エラーが出る

- **破損したアーカイブ**: 一部のファイルが読み取れない場合、エラー回復ダイアログが表示されます。「スキップ」を選択すると、無事なファイルだけを取り出すことができます。
- **パスの長さ制限**: 展開先のパスが非常に長い場合、エラーが発生することがあります。より浅い階層のフォルダを展開先に指定してください。
- **ディスク容量**: 展開先に十分な空き容量があるか確認してください。

### ファイル関連付けが機能しない

- 「関連付け設定」タブで対応形式にチェックが入っているか確認してください。
- 他の解凍ソフトが優先されている場合、Windowsの設定から「既定のアプリ」を確認してください。
