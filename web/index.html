Features

必要なものが、ちょうど全部。

Everything you need, nothing you don't.

日常の圧縮・解凍を、賢く・安全に・速く。Lhamiel は細部まで気が利く設計です。 Smart, safe and fast archiving — thoughtfully engineered down to the smallest detail.

Drag & Drop, Auto-detect

ドラッグ＆ドロップで自動判別

ファイルやフォルダーを落とせば自動で圧縮、アーカイブを落とせば自動で展開。考えることはありません。 Drop a file or folder to auto-compress; drop an archive to auto-extract. Zero thinking required.

ZIP7zTARAuto
Password Protection

パスワード保護

パスワード付き ZIP / 7z の作成に対応。RAR を含む暗号化アーカイブの展開も。 Create password-protected ZIP / 7z, and extract encrypted archives including RAR.

No Double-Nesting

二重フォルダーを防止

展開時の「フォルダーの中にまた同名フォルダー」を賢く回避します。 Smartly prevents the dreaded folder-inside-a-folder when extracting.

Compress Locked Files

使用中ファイルも圧縮

他のアプリが開いてロック中のファイルも、可能な限り圧縮します。 Compresses files that are locked or in use by other applications.

Exclusion List

除外リスト

.DS_Store や node_modules など、不要物を自動で除外。 Automatically skip clutter like .DS_Store and node_modules.

Safe by Design

安全性への配慮

ディスク空き容量の事前チェック、破損アーカイブの可能な限りの復旧、競合時の解決ダイアログ。 Disk-space pre-check, best-effort recovery of corrupt archives, and a file-conflict resolution dialog.

Mark-of-the-Web

MotW を引き継ぎ

インターネット由来の印（Mark-of-the-Web）を展開後のファイルにも適切に伝搬します。 Propagates the Mark-of-the-Web to extracted files for OS security checks.

Themes & Languages

テーマと多言語

ダーク / ライト / システム連動（アクリル・ブラー）。UI は 17 言語に対応。 Dark / light / system themes with acrylic blur. UI available in 17 languages.

File Association

ファイル関連付け

隠しファイル・システムファイルの任意取り込みや、各形式の関連付けにも対応。 Optional hidden / system files and file-type association for each format.
